# F11 · Charts & Returns
Big idea: **returns multiply**. Protecting the downside *is* the growth strategy.

## Charts
- Candle = OHLC for one period; volume = conviction. Timeframes are zoom levels of the same market. Trade the one where you have an edge.
- Use a **log scale** for anything spanning years: equal vertical steps = equal % moves.

## Honest returns
- Think in %, never points (500 points on 40,000 = 1.25%).
- Compare on **total return** (dividends/coupons reinvested).
- **CAGR** = the steady annual rate giving the same end result.
- Real return = nominal − inflation.

## Compounding
- $10k at 7% for 30y ≈ $76k (compounded) vs $31k (simple).
- Loss asymmetry: −50% needs +100%; −20% needs +25%. Recovery gain = 1/(1−loss) − 1.

## Self-test
1. What gain recovers a 30% loss? → ≈42.9%
2. $10k → $20k in 10 years. CAGR? → ≈7.2%
3. Why use a log scale for a 20-year chart? → Equal % moves look equal; linear exaggerates recent moves
4. 8% nominal return, 3% inflation. Real return? → ≈5%
