# F8 · The Toolbox (instruments)
Big idea: everything is **ownership** (equity) or **lending** (debt), plus **wrappers** (funds/ETFs) and **derivatives** (value tracks an underlying).

| Instrument | Essence |
|---|---|
| Stock | Ownership share. Unlimited upside, last in line on failure. |
| Bond | Tradeable loan. Capped upside, senior to equity. |
| Fund / ETF | Basket. ETF trades intraday; ETF flows are a macro signal. |
| Future | Exchange-traded agreement to transact later at a set price. Margin → built-in leverage. The pro macro workhorse. |
| Option | Right, not obligation (call = buy, put = sell) for a premium. Loss capped at premium; nonlinear payoff. |
| Swap | Exchange of payment streams (fixed/floating, currency A/B). Bank plumbing. |
| Index | A calculated number. Traded only via ETFs, futures or options. |

**Choosing an expression**: futures = liquidity and leverage (default); ETFs = simplicity, no expiry; options = defined/asymmetric risk or a view on *size* of move.

## Self-test
1. What's the first question to ask about any new instrument? → Which branch is it / what is its underlying?
2. You want a 3-month EURUSD view with capped loss. Which instrument? → Option
3. Why do futures carry built-in leverage? → You post margin, not the full notional
4. Can you buy "the S&P 500" directly? → No; via ETF, future or options
