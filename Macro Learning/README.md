# Macro Learning
Study notes and self-tests for Nathan's macro/economics study, written as a knowledge base for Claude to use when quizzing and advising.

## Structure
- `MMH Primers/` — Market Macro Hub primers (free; https://marketmacrohubprimers.netlify.app). Condensed notes **in Claude's own words** (not a copy of the site), one file per module, each ending with a self-test.
  - `1 Foundations/` F1–F11 (vocabulary)
  - `2 Basics/` 00–00.9 (the 5-layer framework, data, pricing, positioning, strategy, risk, intraday, regimes), 01–01.4 (FX series), 02 Equities, 03/03.1 Rates, 04 Growth, 05 Inflation, 06 Liquidity, 07 Bitcoin
  - `3 Advanced/` 08–25 (correlations, options signals, combining edges, private credit, FX options, spot & forwards, Greeks, convert arb, STIR, xccy basis, repo, CDS, vol products, SOFR options, corporate bonds, **gold**, silver, AI × macro)
- `TTA Fundamentals/` — The Trading Academy (paid): condensed notes in Claude's own words for all 24 chapters (68 lessons), a course map + teaching/quiz-style file, and practice questions written by Claude in the course's style.
- `Quizzes/` — quiz sessions and a log of weak spots.

## Conventions
- Plain bullets = the course's content, summarised and paraphrased.
- `> [Claude+]` blocks = **Claude's own additions**, not from the course: extra context, formulas, FRED codes, and links to Nathan's gold/FX prop-firm system (SMC, Macro Tracker, four-layer gate). Trim or delete freely.
- `→` after a self-test question = short answer key.

## How to use with Claude
"Quiz me on 00.7 and 05", "10 scenario questions on gold drivers", "test my weak spots", "explain 03.1 using today's data".
